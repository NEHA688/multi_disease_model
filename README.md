# 🧠 Multi-Disease Prediction System

## 📌 Overview

This project is a **Machine Learning-based system** to predict the risk of multiple diseases such as **Diabetes** and **Heart Disease** using structured medical data.

It demonstrates:
- Data preprocessing
- Feature engineering
- Building and evaluating ML models
- Practical usage via a simple interface

This is a great example of a real-world ML workflow from data to prediction.
